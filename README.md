# Thumbnail Generator (Offline Edition)
## Features
- Accepts image + title
- Enhances title locally (rule-based)
- Enhances image (brightness/contrast/sharpen)
- Automatically finds best region for title (low texture/brightness variance)
- Adds text with gradient and shadow
- Fully offline, free, runs locally

## Run
```bash
mvn clean package
mvn spring-boot:run
```
Visit: http://localhost:8080/swagger-ui/index.html
